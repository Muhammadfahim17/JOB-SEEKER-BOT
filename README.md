## 🎯 **О ПРОЕКТЕ**

**Job Seeker Bot** — это мощный Telegram-бот, созданный для帮助 соискателям работы в Таджикистане создать профессиональное резюме и связаться с потенциальными работодателями.

### 🎯 **Основная цель:**
- 📝 Помочь пользователям создать структурированное резюме
- 🤝 Связать соискателей с работодателями
- 📊 Упростить процесс поиска работы
- 💼 Предоставить удобный интерфейс для заполнения анкеты

### 🎯 **Для кого этот бот:**
- 👨‍💼 Соискатели работы
- 👩‍💼 HR-специалисты
- 🏢 Работодатели
- 🎓 Выпускники и студенты

## ⚙️ **УСТАНОВКА**

### **Предварительные требования:**
- Python 3.10 или выше
- PostgreSQL 15 или выше
- Git

### **Пошаговая установка:**

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/yourusername/job-seeker-bot.git
cd job-seeker-bot

# 2. Создайте виртуальное окружение
python -m venv .venv

# 3. Активируйте виртуальное окружение
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

# 4. Установите зависимости
pip install -r requirements.txt

# 5. Создайте базу данных в PostgreSQL
# Войдите в PostgreSQL:
psql -U postgres
# Создайте базу данных:
CREATE DATABASE resume_bot;
# Выйдите:
\q

# 6. Настройте файл .env (см. раздел Настройка)

# 7. Запустите бота
python main.py
```


## 🔧 НАСТРОЙКА

##### Файл .env:
```env
  # Токен вашего бота (получить у @BotFather)
  BOT_TOKEN=ваш_токен_бота

  # ID администраторов (через запятую)
  ADMIN_IDS=123456789,987654321

  # Подключение к базе данных
  DATABASE_URL=sqlite+aiosqlite:///resume_bot.db
```

#### Как получить токен бота:
1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте команду /newbot
4. Следуйте инструкциям
5. Скопируйте полученный токен в .env

#### Как узнать свой ID:
1. Напишите @userinfobot в Telegram
2. Отправьте /start
3. Скопируйте ваш числовой ID
